## 📊 Projects

**[Psychiatric ER Boarding](https://github.com/wanjirurandolph/Psychiatric-ER-Boarding)**
Which hospitals have the longest ER waits for mental health patients? I built a hospital-level
dataset from CMS data in SQL (DuckDB) and used machine learning to find the hospital
characteristics linked to the longest waits.
*SQL · Python · scikit-learn · logistic regression*

**[ACA Marketplace Denials & Appeals](https://github.com/wanjirurandolph/marketplace-denials-analysis)**
Does a high insurance claim denial rate mean inaccurate claim reviews? I analyzed CMS
Marketplace data to test whether insurers that deny more claims are more likely to reverse
those denials on appeal.
*Python · statsmodels · correlation · multiple regression*
